# CU08 - Cerrar sesion

FLUJO DE SUCESOS:
Camino Basico:

1. El usuario elige la opcion "Cerrar sesion".
2. El sistema cierra la sesion actual.
3. El sistema vuelve a la pantalla de login.
4. El usuario queda fuera del sistema.

Caminos Alternativos:

2.a El usuario no tenia una sesion activa.
2.a.1 El sistema lo manda igualmente a la pantalla de login.
